# messiasdias.github.io - LandPage


#### Instalando dependências Projeto
```
yarn install
```

#### Compilando  hot-reloads para ambiente de desenvolvimento
```
yarn start
```

#### Compilando e mimificando arquivos para produção
```
yarn sass
yarn build
```

#### Checando correções de arquivos
```
yarn lint
```
